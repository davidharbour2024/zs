# Zahbro Sports

Fresh production foundation for `davidharbour2024/zs`.

## Stack
- Next.js 16.3.8 Active LTS
- React 19.2.8
- TypeScript 5.9.3
- Tailwind CSS 4.3.3
- GSAP 3.15.0
- Node.js 22.x

## Local development
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation
```bash
npm run check
```
